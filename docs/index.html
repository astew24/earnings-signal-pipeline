earnings-signal-pipeline
Pipeline Files Run GitHub

SEC filings -> FinBERT tone -> PostgreSQL -> simple regression

Can earnings filing language be turned into a testable market signal?

This project takes 8-K filing text, scores management commentary with a finance sentiment model, joins it to short-term price data, and checks the relationship with a simple per-ticker regression.

30 second version

What it reads

SEC 8-K filings and minute-level OHLCV bars from Polygon.io.

What it builds

A database of filings, extracted sentences, FinBERT tone scores, price bars, and regression results.

What it tests

Whether average filing tone has a measurable relationship with next-day open-to-close return.

Pipeline

The page does not show made-up performance numbers. The dashboard in app.py reads whatever is in your local database.

1. Find filingsResolve tickers to CIKs and search EDGAR for 8-K filings.
2. Extract textDownload filing text and keep sentences that look like management commentary.
3. Score toneUse spaCy cleanup and FinBERT positive, neutral, and negative scores.
4. Store dataPersist filings, commentary, tone scores, OHLCV, and analysis rows.
5. Join returnsMatch average filing tone to next-day open-to-close returns.
6. Review outputWrite a Plotly report or open the Flask dashboard.

Run locally

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m spacy download en_core_web_sm
cp .env.example .env

docker compose up -d postgres

python ingestion.py --tickers AAPL MSFT --from-date 2024-01-01 --to-date 2024-06-30
python scoring.py --batch-size 32
python analysis.py --output analysis_report.html
python app.py

Honest limits

This is a research pipeline, not a trading system. Filing extraction is heuristic, event alignment is simple, and any result needs careful controls before it should be treated as evidence of a real signal.
